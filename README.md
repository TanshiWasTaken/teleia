# Teleia
#### semicolon's custom, all-in-one bot

Teleia is a multi-functional, advanced and modern discord bot for semicolon whose purpose is to help with moderation, accomodation, management, economical management, entertainment and many more.

## Definition

el. **τέλεια** /ˈte·li·a/ (adj.)
: perfect

grc. **άνω τελεία**[^1] /ˈa·no te·ˈli·a/ (n. f)
: greek semicolon, upper point, raised point

[^1]: despite the different spelling, the English spelling (and bot's name) - Teleia - is supposed to mean both perfect and semicolon.

## Functionality

### 1. Moderation
<details>
<summary>Teleia offers automated, AI-powered moderation and user-friendly commands for a lighter weight on the staff team's back.</summary>

#### 1. Tweakable AI moderation for blocking inappropriate content
Teleia uses customisable artificial intelligence to automatically detect and block inappropriate content such as spam, NSFW content, hate speech, and more. The AI can be configured to suit the needs of the server and to block specific types of content.

---

#### 2. Tweakable AI moderation for censorship
Teleia also offers AI moderation for censorship, which can be used to censor discussions of triggering or sensitive topics, words used in certain contexts, warn users of a loud video/audio file as soon as it was sent etc.

---

#### 3. Intuitive and user-friendly commands for staff
Teleia provides intuitive and user-friendly commands for staff members to help them manage the server more efficiently without giving them any headaches or dread in doing so, thanks to the ease of use of its moderation commands.

---

#### 4. Strike system integration with designated database
Teleia includes a strike system that allows staff members to track user behaviour, issue warnings and pardon/penalise users with strikes accordingly. The strikes are recorded in a designated database collection, allowing staff members to easily access and review user history, while also providing for an easy method of storing this information.

---

#### 5. Automatic moderation
Teleia can also perform moderative actions based on user behaviour. For example, if a user receives a certain number of strikes, Teleia can then penalise the user according to the amount of strikes the user has. This feature helps to reduce the workload of staff members and ensures rule violations are dealt with consistently and constantly.

---
  
</details>

### 2. Accommodation
<details>
<summary>Teleia offers accommodation features to make users feel welcome and prevent them from getting overwhelemed.</summary>

#### 1. Welcome messages
Teleia will send a message welcoming each new member who joins the server. This message includes a greeting, general guide on how to get set-up in the server, and links to important resources. Offering a warm welcome can help create a friendly and inviting atmoshpere, encouragin new members to engage with the community.

---

#### 2. Verification system
Teleia's verification system is a multi-step automated process with manual approval by staff members designated to prevent spam and protect the community from unwanted or malicious users. When new users join the server, they are to complete the automated verification process before opening a ticket to talk with one of our staff members to get approved into the server. This feature helps mantain the server's security and prevent bots, spammers and trolls from joining the server.

---

#### 3. Self-assignable roles
Teleia's self-assignable roles feature allows users to choose which roles they want to assign to themselves, granting them greater control over their server experience. This can include things like preferred pronouns, interests, age group, or other criteria. This feature allows users to find like-minded individuals with similar interests.

---

#### 4. Birthday database
Teleia keeps track of users' birthdays if they choose to set it and send automated messages to celebrate their special day. This can help foster a sense of community and make users feel valued and appreciated as other users will see this celebrartory message and wish the celebrated one a happy birthday.

---

#### 5. Feedback
Teleia's user feedback system allows users to provide feedback on the server and its features, which can be used to improve the server and enhance the user experience.

---
  
</details>

### 3. Management
<details>
<summary>Teleia offers a variety of management features to help the server owners and staff members keep their server organized and running smoothly.</summary>

#### 1. Server statistics and analytics
Teleia provides server statistics and analytics to help administrators understand more about the server. This includes information on user engagement, text and voice channel activity, server growth over time, age groups etc. Teleia also provides insights into which commands are most frequently used and which areas of the server are most active. This information can help administrators make data-driven decisions to improve the server's performance and engagement.

---

#### 2. Scheduling
Teleia's scheduling feature makes it easy to plan and coordinate events and reminders. With this feature, staff members can schedule events and members can set reminders for themselves and get notified when events are coming up. This keeps the community engaged and informed and makes it easier to plan and organise activities.

---

#### 3. Role-based access control
Teleia's role-based access control system allows administrators to control access to different server features, resources and channels based on a user's role.

---

#### 4. Integration with external tools and services
Teleia can integarte with various external tools and services, such as social media platforms, webhooks and API endpoints. This allows for seamless integration with other tools and services, providing administrations with additional functionality and flexibility for managing the server.

---

#### 5. Ticket system
Teleia's ticket system helps streamline user requests and support issues by providing an automated way for users to open tickets and for staff members to manage and respond to those tickets. This helps improve the user experience and ensure that requests are addressed in a timely and efficient manner.

---

#### 6. Logs
Teleia tracks and logs all server events, including user actions, moderation actions, and more. This information can be used to investigate incidents or disputes and maintain accountability for users', including staff members', actions.

---
  
#### 7. Leveling system
Teleia's leveling system has its own designated database collection. It will keep track of the amount of messages a member has sent in the server in order to assign them a level. Users are able to reach level milestones, which when they do, they're rewarded with a prize. There is a leaderboard specific for levels which ranks users based on their level.
  
---
  
</details>

### 4. Economy
<details>
<summary>Teleia offers an economy feature to institute a local currency system not only to keep users engaged and incentivise participation, but to also offer a medium of exchange for virtual goods and services.</summary>
  
#### 1. Currency system
Teleia's economy system includes a currency that can be earned by participating in activities, such as chatting, participating in events, or completing tasks assigned by staff members. This currency can be used in exchange for virtual goods and services offered by other members.

---

#### 2. Shop system
Teleia's economy system provides a shop where users can spend their earned currency on various items. These items can include, but are not limited to, custom roles, custom pieces of literature, custom drawings and whatever other users have decided to sell.
  
---
  
#### 3. Lottery system
Teleia's lottery system allows users to spend currency on lottery tickets. At set intervals, a random drawing is held and the winner receives a prize, such as a large sum of currency or a special reward.
  
---
  
#### 4. Leaderboard
Teleia's economy system includes a leaderboard, which ranks users based on their total earned currency. This can help incentivise friendly competition and encourage users to participate in server activities to earn more currency and climb the leaderboard.
  
---
  
#### 5. Logs
Teleia tracks all transcations and changes to user currency balances, allowing administrators to audit the system and investigate any discrepancies. This helps ensure the system is fair and transparent for all users.
  
---
  
#### 6. Auction system
Teleia's economy system offers an auction system, allowing users to bid on items or services offered by other users or the staff team. This creates a sense of competition and excitement within the community and provides users with a new way to engage with each other.

---
  
</details>

### 5. Entertainment
<details>
<summary>Teleia offers various entertainment features to keep users engaged and entertained within the server.</summary>

#### 1. Games and activities
Teleia offers various games and activities such as trivia, would you rather, quizzes, truth or dare etc., as well as activities such as movie nights, stand up comedy and any others that administrators come up with. Users who participate and win in activities will receive currency or a special reward.
  
---
  
#### 2. Music and radio
Teleia's music and radio feature allows users to play music within the server in a voice channel. Users can spend an undetermined amount of currency for a playlist slot where they can save their favourite songs and have a seamless listening session without having to add each song every time. Additionally, Teleia can also stream radio stations from around the world, allowing users to listen to their favourite radio stations from within the server.
  
---
  
#### 3. Virtual pets and games
Teleia's virtual pets and games feature allows users to adopt and care for virtual pets, play games and earn rewards within the server. Users can play chess against other users and if they win, they can earn currency based on the difficulty they faced against their opponent. This can be a fun way to keep users invested, as well as provide a sense of accomplishment and achievement.
  
---
  
#### 4. Special events and challenges
Teleia is able to host special events and challenges from which users are able to earn rewards and prizes based on their contribution in the event or challenge.
  
---
  
#### 5. Clubs
The server's structure allows for Teleia to engage with each club in unique ways that match the club's topic.

---
  
#### 6. Personality
Teleia uses artifical intelligence while generating responses to certain commands or auto-responders in order to give Teleia a personality. This can help with removing the user-machine barrier and making Teleia more approachable for users to interact with.
  
</details>
