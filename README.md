# Teleia
#### semicolon's custom, all-in-one bot

Teleia is a multi-functional, advanced and modern discord bot for semicolon whose purpose is to help with moderation, accomodation, management, economical management, entertainment and many more.

## Definition

el. **τέλεια** /ˈte·li·a/ (adj.)
: perfect

grc. **άνω τελεία**[^1] /ˈa·no te·ˈli·a/ (n. f)
: greek semicolon, upper point, raised point

[^1]: despite the spelling being different, the English spelling (and bot's name) - Teleia - is supposed to mean both perfect and semicolon.
