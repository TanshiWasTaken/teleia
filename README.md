# Teleia
#### semicolon's custom, all-in-one bot

Teleia is a multi-functional, advanced and modern discord bot for semicolon whose purpose is to help with moderation, accomodation, management, economical management, entertainment and many more.

## Definition

el. **τέλεια** /ˈte·li·a/ (adj.)
: perfect

grc. **άνω τελεία**[^1] /ˈa·no te·ˈli·a/ (n. f)
: greek semicolon, upper point, raised point

[^1]: despite the different spelling, the English spelling (and bot's name) - Teleia - is supposed to mean both perfect and semicolon.

## Functionality

1. Moderation
   - Tweakable AI for blocking inappropriate content
   - Tweakable AI for censorship
   - Easy and intuitive commands for staff
   - Strike system integration with designated database collection
   - Automatic moderation

Teleia offers customisable AI moderation to block inappropriate content, intuitive staff commands for managing the server, a strike system to track user behavior, and automatic temporary mutes or bans based on strikes for an easier weight on the staff team's back.
